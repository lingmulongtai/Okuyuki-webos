# Okuyuki TV 0.1.1 プレビュー

Android の Okuyuki alpha.13 と同じ Wi-Fi で接続し、承認後に写真・動画をテレビから選べる検証用 IPK です。[インストール、接続、自動更新補助ツールの手順](https://github.com/lingmulongtai/Okuyuki-webos/blob/v0.1.1-alpha.1-preview/docs/TV.md)を参照してください。

テレビでの IPK の導入には開発者モードと PC の `ares-install` が必要です。更新補助ツールは、PC が起動していてテレビに接続できる間、自動で更新を確認・検証・インストールします。テレビ単体での自動インストールは未対応です。

Galaxy・LG テレビ実機でのペアリング、写真・動画表示、4K、変換、更新補助ツールは未検証です。通信は承認付き HTTP のため、信頼できるネットワークでお試しください。
