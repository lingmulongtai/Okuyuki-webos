# Okuyuki TV 0.1.9 プレビュー

Android の Okuyuki alpha.13 と同じ Wi-Fi で接続し、承認後に写真・動画をテレビから選べる検証用 IPK です。[インストール、接続、更新の手順](https://github.com/lingmulongtai/Okuyuki-webos/blob/v0.1.9-alpha.1-preview/docs/TV.md)を参照してください。

0.1.3〜0.1.8 をインストール済みなら、テレビ単体で画面更新を取得し、次回起動時に適用できます。0.1.2 以前からは、この IPK を PC の `ares-install` で一度導入してください。その後、互換性のある画面更新はテレビ単体で署名を確認して保存し、次回起動時に適用します。0.1.6 の画面では、以後の更新を保存した際に「今すぐ適用」でアプリを再起動できます。0.1.7 の画面では、更新確認が失敗した場合も 30 秒後から間隔を広げて自動的に再試行します。0.1.8 の画面ではテレビでアプリを再表示した時にも更新を確認し、IPK の公開情報の一時的な取得失敗から自動で再試行します。アクセス制限中は解除時刻まで待機します。0.1.9 の画面では更新確認が長時間進まない場合に再起動して再確認でき、接続前に画面版と IPK 版を確認できます。旧 IPK は起動時に保存領域を開けない場合、同梱画面へ戻るため、この復旧案内は表示されません。テレビでアプリを開き直すか、0.1.9 IPK を PC から導入してください。IPK の導入だけで保存領域の障害が解消するとは限りません。互換性のない変更は IPK の再導入が必要です。PC 用の更新補助ツールも利用できます。

Galaxy・LG テレビ実機でのペアリング、写真・動画表示、4K、変換、テレビ単体の更新と PC 用更新補助ツールは未検証です。通信は承認付き HTTP のため、信頼できるネットワークでお試しください。
