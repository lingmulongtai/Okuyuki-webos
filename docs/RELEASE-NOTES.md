# Okuyuki TV 0.1.6 プレビュー

Android の Okuyuki alpha.13 と同じ Wi-Fi で接続し、承認後に写真・動画をテレビから選べる検証用 IPK です。[インストール、接続、更新の手順](https://github.com/lingmulongtai/Okuyuki-webos/blob/v0.1.6-alpha.1-preview/docs/TV.md)を参照してください。

0.1.3〜0.1.5 をインストール済みなら、テレビ単体で画面更新を取得し、次回起動時に適用できます。0.1.2 以前からは、この IPK を PC の `ares-install` で一度導入してください。その後、互換性のある画面更新はテレビ単体で署名を確認して保存し、次回起動時に適用します。0.1.6 の画面では、以後の更新を保存した際に「今すぐ適用」でアプリを再起動できます。互換性のない変更は IPK の再導入が必要です。PC 用の更新補助ツールも利用できます。

Galaxy・LG テレビ実機でのペアリング、写真・動画表示、4K、変換、テレビ単体の更新と PC 用更新補助ツールは未検証です。通信は承認付き HTTP のため、信頼できるネットワークでお試しください。
