# Okuyuki TV（テレビアプリ）

スマホの Okuyuki に入っている写真と動画を、LG webOS テレビで見るアプリです（`com.okuyuki.tv`）。
写真はまず 1920×1080 の標準画質で出し、スマホが 4K の静止画（テレビの動画プレーンに出す、1 枚だけの動画）を用意できたら、それに切り替えます。右上の表示が「標準」から「4K」に変わるのが目印です。

スマホ側のプロトコル v2 と 4K への変換は Okuyuki-android のアプリが受け持ちます。テレビアプリは手動で起動し、スマホに表示されたアドレスを入力してください。スマホがなくても、PC で動く[モックホスト](#pc-の写真でテレビを試す)をスマホの代わりに使えます。

## リモコン

| ボタン | 一覧 | 写真 | 動画 |
| --- | --- | --- | --- |
| 十字キー | 移動 | ← → で前後の写真、↑ ↓ で情報の表示を切り替え | 操作パネル |
| 決定 | 開く | 情報の表示を切り替え（動画なら再生） | 再生・一時停止 |
| 戻る | 終了の確認 | 一覧に戻る | 操作パネルを閉じる、もう一度で一覧に戻る |
| 再生 | | 動画を再生 | 再生 |

写真の日付や画質の表示は、5 秒たつと消えます。マジックリモコンでは、写真の左 3 分の 1 をクリックすると前、右 3 分の 1 で次、真ん中で情報の表示を切り替えます。

一覧の右上の「設定」で「写真を最高画質（4K）で表示する」をオフにすると、標準画質だけで表示します（既定はオン）。

## アプリの更新

0.1.3 は、起動時と起動中に定期的に署名付きの画面更新を確認します。スマホ未接続の画面と接続後の設定から「更新を確認」も選べます。互換性がある更新はテレビ内に保存し、次にアプリを開いたときに適用します。署名が不正な場合、通信できない場合、更新に必要な同梱ファイルが異なる場合は現在の版を使い続けます。更新版が起動に失敗した場合は同梱版へ戻ります。

画面更新は IPK 自体を更新するものではありません。アプリの権限、同梱アセット、起動処理などに変更が必要な場合は、従来どおり [GitHub Releases](https://github.com/lingmulongtai/Okuyuki-webos/releases) の新しい IPK を `ares-install` で導入してください。0.1.3 は更新の起動処理自体を改修したため、0.1.2 以前からは PC で 0.1.3 の IPK を一度インストールしてください。以後も IPK や同梱ファイルが変わる更新には再導入が必要です。テレビでの自動更新の動作は実機未検証です。

互換性のない IPK の更新も、PC で webOS CLI のデバイス登録を済ませていれば、PC を起動している間は補助ツールに任せることができます。リポジトリを PC に取得して `npm ci` を実行した後、登録した名前を指定します。

```sh
npm run tv:auto-update -- --device myTV
```

起動時とその後 1 時間ごとに TV のインストール済みバージョンと GitHub Releases を確認し、新しい IPK のサイズと SHA-256 を確認してから `ares-install` を実行します。終了は Ctrl+C、1 回だけ確認する場合は末尾に `--once` を付けます。PC とテレビが同じネットワークにあり、テレビの開発者モードが有効である必要があります。PC を終了・スリープしている間は動作せず、GitHub の通信制限中は次回まで再試行します。この仕組みは実テレビで未検証です。

## Android とつなぐ

1. Android とテレビを同じ Wi-Fi につなぎ、Android の Okuyuki で「接続」を開いて待機をオンにします。写真と動画のアクセスを求められたら、見せたい項目を許可します。
2. テレビで Okuyuki TV を開き、Android の画面に表示される `IPアドレス:ポート` を入力します。
3. 両方に同じ 4 桁の番号が表示されたことを確認し、Android で接続を許可します。テレビの一覧から写真や動画を選べます。

この接続、4K 出力、動画の形式変換は実機での検証前です。Android とテレビの双方がアクセスできるプライベートネットワークで試してください。

## PC の写真でテレビを試す

スマホがなくても、PC の写真フォルダをスマホの代わりにしてテレビアプリを試せます。

1. テレビの開発者モードと `ares` コマンドの準備は、[4K 静止画テスト](STILL4K.md)の 1 と 2 と同じです。
2. IPK を用意します。GitHub Actions の `okuyuki-tv-ipk` をダウンロードするか、自分でビルドします。

   ```sh
   npm ci
   npm run tv:install
   npm run tv:build
   npm run tv:package        # dist/com.okuyuki.tv_0.1.3_all.ipk
   ares-install --device c5 dist/com.okuyuki.tv_0.1.3_all.ipk
   ```

3. PC でモックホストを起動します。ffmpeg が必要です（Windows なら `winget install Gyan.FFmpeg`）。

   ```sh
   npm run mock-host -- --photos "C:\Users\me\Pictures\テレビ用"
   ```

   フォルダ直下の JPEG・PNG・WebP の写真と、MP4・MOV・WebM の動画を使います（HEIC はモックでは読めません）。ターミナルに「テレビで入力するアドレス」が出ます。Windows で通信の許可を聞かれたら、プライベートネットワークで許可してください。
4. テレビで Okuyuki TV を開き、「アドレスを入力してつなぐ」の欄にそのアドレスを入れて「つなぐ」を押します（ポートが 38765 なら省けます）。テレビに 4 桁の番号が出て、ターミナルにも同じ番号が出るので、`y` を入力して Enter を押します。
5. 一覧から写真を開きます。数秒で右上が「4K」に変わり、写真が 4K で表示されます。`--photos` を付けずに起動すると、番号入りの合成写真 150 枚で試せます。合成写真の右下の番号の灰色の地は、4K に切り替わると 1 ピクセルの市松模様になるので、近くで見ると違いが分かります。

テレビとの許可は、モックホストを起動し直すと消えます（番号の確認からやり直しです）。

## しくみ

1. テレビは、スマホから起動されたときの引数、前回つないだスマホ、入力されたアドレスの順に接続先を決めます。
2. `GET /v1/hello` でスマホがテレビ用のプロトコル（v2）に対応しているか確かめ、初めてのテレビなら 4 桁の番号で許可を求めます。許可されるとトークンを受け取り、テレビアプリの中に保存します。
3. トークンでメディアキー（12 時間有効）を受け取り、テレビの画面の大きさと再生できる形式をスマホに伝えます。以降の一覧、画像、動画はすべてメディアキー付きの URL で受け取ります。
4. 写真を開くと、標準画質の画像（1920×1080）をすぐ出し、同時にスマホに 4K の静止画を頼みます。スマホは C5 なら HEVC Main10 で、写真を 3840×2160 に収めた 1 枚の動画を作ります。テレビは最初のフレームが出たところで止め、標準画質の画像と入れ替えます。表示中に、次の写真の 4K も先に作ってもらいます。
5. 動画はテレビの標準プレーヤーで再生します。テレビが再生できる形式なら元のファイルをそのまま、できなければスマホが変換します。

写真や動画のデータはテレビに保存しません（応答はすべて `Cache-Control: no-store`）。テレビに残るのは、トークン、前回のスマホのアドレス、設定だけです。プロトコルの詳細は [protocol/README.md](../protocol/README.md) にあります。

## 開発

```sh
npm run tv:install                 # apps/tv の依存関係
npm --prefix apps/tv run serve     # http://localhost:8080 で開発用サーバー
npm run mock-host                  # 別のターミナルで、スマホの代わり
```

デスクトップのブラウザでは、「アドレスを入力してつなぐ」の欄に `127.0.0.1` を入れて接続します。許可はモックホストのターミナルで `y` を入力します。

| コマンド | 内容 |
| --- | --- |
| `npm run tv:lint` | Enact の lint（strict） |
| `npm run tv:test` | プロトコルのフィクスチャ、通信、接続の状態などの単体テスト |
| `npm run tv:build` | 本番ビルド（`apps/tv/dist`）。iLib のロケールデータは日本語と英語（米国）だけ残します |
| `npm run test:tv` | 本番ビルドとモックホストで、1920×1080 の画面をブラウザで確かめる（先に `tv:build`） |
| `npm run tv:package` | `dist/` に IPK を作る |

モックホストは `/__mock/*` で操作できます。`approve`・`reject`（許可）、`show?id=`（スマホで選んだ写真を表示）、`library_changed?add=1`（写真が増えた）、`revoke`（許可を取り消す）、`close`（スマホで接続をオフにした）、`delay?ms=`（スマホでの 4K や動画の準備にかかる時間）、`reset`、`state`（いまの状態）です。ブラウザのテストもこれを使います。

## 既知の制限

- 4K 静止画の出し方（再生して最初のフレームで止める）は、[4K 静止画テスト](STILL4K.md)の結果を見て決め直します。
- モックホストが作る 4K 静止画は SDR です。Ultra HDR 写真を HDR で出すのはスマホ側の変換で行います。
- 3D 写真は片目の 2D 写真として表示します。
